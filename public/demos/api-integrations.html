Benve Control API — Documentation

A. API endpoints

POST /api/v1/evidence/upload

Upload evidence files programmatically

Authentication: API key or OAuth 2.0Rate limit: 100 requests/minute
GET /api/v1/controls/{control_id}/test-results

Retrieve test results for a control

Filters: date range, status, exception flagResponse format: JSON
POST /api/v1/ccm/events

Push CCM events from external systems

Authentication: API keyRate limit: 1000 events/minute

B. Webhooks

  • control.exception_detected — Triggered when CCM detects an exception
  • evidence.submitted — Triggered when client uploads evidence
  • deficiency.remediated — Triggered when deficiency is marked as remediated
